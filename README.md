# 🤖 AI-Projects

Welcome to **AI-Projects**, a curated collection of my Artificial Intelligence, Machine Learning, Deep Learning, and Large Language Model (LLM) projects. This repository serves as a central portfolio of my work, showcasing practical implementations, research-driven solutions, and real-world AI applications.

The projects included here span traditional machine learning, deep learning, computer vision, natural language processing, generative AI, Agentic AI, Retrieval-Augmented Generation (RAG), and MLOps. Each project is organized in its own directory with source code, documentation, datasets (where permitted), and instructions for reproduction.
